# <glob> <skill> [<regex>]
# A changed file loads every skill whose glob matches it. `*` matches across `/`.
# With a regex, the skill loads only when a line the diff adds to that file matches it
# (grep -E). The regex runs to the end of the line and must not contain spaces.
# First match does not stop the search: a file can load many skills.
